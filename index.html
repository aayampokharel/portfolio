I'm a backend engineer who writes Go for a living and for fun. I have 1+ years of professional experience building REST APIs, caching layers, optimized queries and Dockerized deployments. Outside work, I build and ship my own systems: a live EdTech platform, a Byzantine-fault-tolerant blockchain written from scratch, and real-time multiplayer backends.

I care about the parts of backend work that don't show up in a demo — typed APIs that can't be called wrong, queries that stay fast when the table grows, caches that don't lie, and deploys that nobody notices. Most of my spare time goes into concurrency, distributed systems, consensus and real-time systems.

GITHUB · AAYAMPOKHAREL/FYP_BACKEND

DocSniff

Permissioned consortium blockchain · Final-year project

A private, permissioned blockchain for issuing and verifying academic certificates — consensus, networking and storage written from scratch.

  • Hybrid simplified PoW + PBFT consensus (Pre-Prepare → Prepare → Commit → Execute) — 4 nodes tolerating 1 Byzantine node
  • Custom raw-TCP peer-to-peer layer for block propagation and consensus messages
  • RSA-signed consensus messages, SHA-256 Merkle trees with inclusion proofs
  • PostgreSQL persistence (8 normalized tables) + Go reverse proxy for public QR-code verification
  • Python background-removal step (called from Go) for institution logos & signatures
  • Flutter dashboard for admins and institutions
